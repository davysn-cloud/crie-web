## Palavras-chave negativas

Excluir buscas que nao sao ICP:

| Palavra negativa | Por que excluir |
|---|---|
| gratis | Atrai quem nao quer pagar (exceto se tiver campanha especifica de trial) |
| curso | Pessoas buscando educacao, nao ferramenta |
| vaga | Busca de emprego |
| emprego | Busca de emprego |
| freelancer | Nao e ICP |
| template gratis | Busca de recurso gratuito |
| como criar agencia | Empreendedor iniciante, nao agencia existente |
| o que e | Busca muito informacional, nao transacional |
| download | Busca de software desktop, nao SaaS |
| crackeado / pirata | Obvio |
| salario | Busca de emprego |
| estagio | Busca de emprego |
